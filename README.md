# 🚀 FastAPI AI Content Analyzer

A modern Python backend service built with **FastAPI**. This project demonstrates my ability to build clean, containerized, and production-ready APIs.

## 🎯 Features
- REST API design with FastAPI
- Async HTTP requests using `httpx`
- Web scraping using `BeautifulSoup`
- Ready for AI integration (LLM summarization)
- Fully containerized with Docker

## 🛠 Tech Stack
- **FastAPI** (Modern Python framework)
- **Docker** (Containerization)
- **httpx** (Async HTTP client)
- **BeautifulSoup** (HTML parsing)

## 🚀 Quick Start (Docker)

```bash
docker build -t fastapi-analyzer .
docker run -p 8000:8000 fastapi-analyzer
